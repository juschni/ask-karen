Ask Karen – Installation

Ziel

Diese Anleitung beschreibt die Einrichtung von Ask Karen Mail Assistant.

Die erste Version ist für die Nutzung auf dem iPhone ausgelegt.

⸻

Voraussetzungen

Benötigt:

* iPhone mit iOS
* Apple Kurzbefehle App
* Internetverbindung
* KI-Schnittstelle für die Verarbeitung

⸻

Installation (Version 1)

Schritt 1

Apple Kurzbefehle öffnen.

⸻

Schritt 2

Den Shortcut “Ask Karen” hinzufügen.

⸻

Schritt 3

Berechtigungen bestätigen:

* Zugriff auf geteilte Inhalte
* Verarbeitung von Text
* Ausgabe von Ergebnissen

⸻

Schritt 4

Eine E-Mail öffnen.

⸻

Schritt 5

Teilen auswählen.

⸻

Schritt 6

“Ask Karen” auswählen.

⸻

Ergebnis

Ask Karen erstellt:

* Übersetzung
* Zusammenfassung
* wichtige Informationen
* Antwortvorschlag

⸻

Datenschutz

Ask Karen verarbeitet Inhalte nur für den jeweiligen Vorgang.

Es werden keine Inhalte dauerhaft gespeichert, sofern keine zusätzliche Speicherung aktiviert wurde.

⸻

Zukunft

Geplante Erweiterungen:

* automatische E-Mail-Analyse
* PDF-Unterstützung
* Sprachsteuerung
* Sicherheitsprüfung
* Kalenderintegration
