# Ask Karen

## Dein persönlicher KI-Assistent

Ask Karen ist ein KI-basiertes Assistenzsystem, das alltägliche Kommunikation einfacher macht.

Die erste Anwendung ist:

## Ask Karen Mail Assistant

Ein intelligenter E-Mail-Assistent für iPhone-Nutzer.

---

# Ziel

Eine einfache Möglichkeit schaffen, fremdsprachige Nachrichten sofort zu verstehen.

Ohne Kopieren.
Ohne Apps zu wechseln.
Ohne komplizierte Bedienung.

---

# Version 1 – Mail Assistant

## Funktionen

- Automatische Spracherkennung
- Natürliche Übersetzung
- Zusammenfassung langer Nachrichten
- Erkennung wichtiger Informationen
- Erkennung von:
  - Terminen
  - Fristen
  - Beträgen
  - Kontaktdaten
  - Links

- Erstellung von Antwortvorschlägen

---

# Bedienung

Workflow:

E-Mail öffnen

↓

Teilen

↓

Ask Karen auswählen

↓

Analyse erhalten

---

# Vision

Ask Karen soll ein persönlicher digitaler Begleiter werden.

Nicht komplizierter.
Nicht technischer.

Einfach:

"Zeig mir, was diese Nachricht bedeutet."
