Ask Karen – iOS Shortcut Setup Guide

Ziel

Diese Anleitung beschreibt die Einrichtung von Ask Karen als iPhone-Kurzbefehl.

Ziel ist eine schnelle Nutzung direkt aus dem Teilen-Menü.

⸻

Voraussetzungen

Benötigt:

* iPhone (ab iOS-Version mit Kurzbefehle-App)
* Internetverbindung
* Apple Kurzbefehle App
* KI-Verbindung für die Verarbeitung

⸻

Einrichtung

1. Kurzbefehle öffnen

Die App “Kurzbefehle” auf dem iPhone öffnen.

⸻

2. Neuen Kurzbefehl erstellen

Einen neuen Kurzbefehl anlegen.

Name:

Ask Karen

⸻

3. Eingabe aktivieren

Der Kurzbefehl muss Inhalte aus dem Teilen-Menü akzeptieren.

Aktivieren:

“Im Teilen-Menü anzeigen”

⸻

4. Eingaben verarbeiten

Der Shortcut erhält:

* Textinhalt einer E-Mail
* Nachrichtentext
* optional weitere Informationen

⸻

5. KI-Verarbeitung starten

Die Eingabe wird an die KI-Schnittstelle übergeben.

Verarbeitung:

1. Sprache erkennen
2. Übersetzen
3. Zusammenfassen
4. Wichtige Informationen erkennen
5. Antwortvorschlag erstellen

⸻

6. Ergebnis anzeigen

Die Ausgabe wird übersichtlich dargestellt.

Beispiel:

📝 Zusammenfassung
⚠️ Wichtig
🇩🇪 Übersetzung
✍️ Antwortvorschlag

⸻

Test

Testablauf:

1. Englische E-Mail öffnen
2. Teilen auswählen
3. Ask Karen starten
4. Ergebnis prüfen

⸻

Fehlerbehebung

Shortcut erscheint nicht

Prüfen:

* Teilen-Menü aktiviert
* Kurzbefehle-App erlaubt
* iPhone neu gestartet

⸻

Ergebnis unvollständig

Prüfen:

* vollständiger Text wurde übergeben
* Internetverbindung vorhanden
* KI-Verbindung aktiv

⸻

Zukunft

Geplante Verbesserungen:

* One-Tap Installation
* eigene Ask Karen App
* Offline-Funktionen
* Sprachsteuerung
* persönliche Lernprofile
